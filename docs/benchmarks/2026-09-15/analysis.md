# 选型结论与错例分析

在当前抓取审核流程下，建议继续以 **`qwen3.8-max-0902` 为基线**。本轮 98 条固定回归中命中 88 条（89.8%），原价估算 ¥43.28，平均 ¥0.4416/条；两次 API 调用合计的 P50 为 26.59 秒。完整指标及计算口径见[benchmark 报告](README.md)，逐条结果见 [episodes.csv](episodes.csv)。

Max 对 78 条坏例正确拒绝 74 条，误放 3 条，另有 1 条执行失败；20 条正例通过 14 条，误拒 4 条、待复核 2 条。它在本轮的全量命中数和坏例正确拒绝数均为最多，但正例通过率只有 70%，仍需改进物品一致性与悬空判断。现有 GT 分类下，反复重试 10 条、动作不完整 5 条和画面模糊 10 条的最终标签均命中；这些数字没有单独评估模型解释是否正确。

`qwen3.7-plus-2026-05-26` 命中 69/98，已知原价约 ¥7.31，但误放 17 条；`qwen3.5-plus-2026-02-15` 命中 63/98、约 ¥3.06，误放 13 条。两者费用较低，当前结果还不足以支持按低单价直接替换 Max。`qwen-vl-max` 没有执行失败，但仍误放 18 条；接口可靠性与审核正确性需要分别评估。

这批数据包含 20 正例、78 坏例：把所有记录都拒绝也能获得 79.6% 的总命中率，却无法通过任何正例。因此报告同时列出正例通过、坏例拒绝、覆盖率和平衡命中率。数据此前参与过 prompt 开发，本轮是已知数据回归，不能把结果推广为新任务或新数据上的准确率。

## 输出契约对结果的影响

`qwen3.8-flash` 的 43 条执行失败中，36 条发生在画质阶段，7 条在证据校验阶段。一个实际例子是 `231c173c522716a72aecbfbe6d3b1387`：画质响应除了 `quality_by_camera` 还返回 `task_rules`，被现有接口拒绝。它的 ¥2.81 费用对应 45/98 的全量命中，不能只看已成功判定部分的准确率。

`qwen3-vl-flash-2026-01-22` 有 72 条在证据阶段失败，最终仅命中 24/98；虽然总原价约 ¥0.75，当前可用率较低。首条 `00acf09c6217f6aa3df1a38469d498a5` 的 `hold` 包含契约外的 `start_time_s`、`end_time_s` 和 `duration_s`。各失败记录的具体字段错误保存在 `episodes.csv` 的 `schema_failure` 列。

Max 已请求 strict JSON Schema，仍有 1 条回包不符合契约：`2eb54be92d4383a1929ee63acd74467c` 的检查项返回字符串而非对象，缺少观察记录，并返回了契约外字段和枚举值。应用层校验捕获了这个问题。发送结构约束不能替代接收后的校验。

本轮沿用现有适配器，Max 请求 JSON Schema，其他模型请求 JSON object；结果同时受到模型能力和输出契约适配程度影响。若继续比较视觉判断能力，应另开实验统一可接受的输出协议，再用未参与 prompt 开发的数据验证。本轮未修复回包、改判或为提高分数补跑。

## 费用对账与验证

本轮共 686 个模型与样本组合、1,372 次 HTTP 尝试：687 次任务调用、685 次画质调用。Qwen3.7-Plus 有一次任务请求读取超时（180.29 秒）后重试；另一个样本 `9c0b19fdc7191fb602898b65d756dda4` 输出达到 5,000 token 上限，`finish_reason=length`，因此未继续调用画质模型。这恰好抵消一次新增重试，不能把每个模型的 196 次请求理解为每条都成功完成两次调用。

有用量回执的请求共消耗 21,729,368 输入 token、1,012,675 输出 token，合计 22,742,043 token。公开原价估算 **¥67.2681**；按回执中缓存命中及对应公开缓存单价折算的已知金额为 **¥64.6890**。超时请求没有 usage，费用未知，未计入这两个已知金额；它们也没有扣除免费额度或账户优惠，均不是账户账单金额。单价来源和分阶梯计算见报告中的价格表。

全部 1,372 份请求已与冻结样本和调用阶段的消息逐一核对；结果范围、配置来源、代码与 prompt 快照核验通过。统计保留全部 98 条分母，GT 只用于离线评测。原始输入只读，原始调用与结果保留在 `artifacts/experiments/model_benchmark_20260915/`。

本轮工程验证：完整自动化测试 **120 passed、1 skipped**，`just check` 通过；报告相关测试覆盖费用阶梯、缓存不重复计费、失败与未知用量、断点保护、输入一致性和重复生成。普通测试使用假客户端；真实模型试验的费用已经计入本报告。
