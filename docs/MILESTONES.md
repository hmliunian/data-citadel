本地 HTTP 启动检查通过：首页、健康检查、277 条记录/10 个动作的列表，以及真实记录审核响应和结果落盘。CLI 抽帧实际导出 4 张 JPEG，保持源时间戳。真实 Qwen 连通性已在 M2 单独验证。

## M4：按原子动作匹配专家、沿用原审核与 Ground Truth 对照

按用户确认，任务唯一依据是 action_id；物体、task_code 和采集员不再拆分任务。专家沿用 correct + Accepted + 原审核人记录，共享源审核校验，运行时重新检查，并保持五条独立引用、专家与测试无交叉。

当前 282 条本地样本生成 10 组已启用专家：50 条专家、50 条独立正确测试，合计 232 条测试。旧三份配置已备份至 artifacts/experts-v1.GvGfzM/，默认 config 已切换到 same_action_v2。错误类配额仍有缺口，不表示完整 400 条分类实验已完成。

专家匹配不可用时仍执行通用审核；专家采样和模型运行异常仍作为运行错误处理。保留严格的时间证据、采样警告和正确放行门槛。网页以 GT 在上、Predict 在下对照原人工标签与单个最终标签；多个已确认错误时只展示第一项，全部错误与 Qwen 原始分项保留在展开详情。另可展开五专家参考和任务判断；原人工标签不进入模型请求。源标签缺失时显示未提供，切换记录不会把另一条记录的标签配到旧响应上。

验证：全量 CITADEL_REAL_MCAP=1 .venv/bin/python -m pytest -q 得到 **147 passed**，包含 3 条真实 MCAP、6 个模拟模型集成场景和 6 个 Node 最小 DOM 前端行为测试（含单 Predict、GT 对照与折叠分项）。Ruff 与 git diff --check 通过；无新增运行依赖。
